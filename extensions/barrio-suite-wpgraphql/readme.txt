The Barrio Suite forms in WPGraphQL, for headless frontends.

== Description ==

Adds `hbForm`, `hbForms` and `hbSubmitForm` to the WPGraphQL schema, with the same names and types as the previous Suite Barrio plugin, so existing headless frontends keep working unchanged. Submissions go through the same pipeline as the REST API, spam checks and file checks included. Without WPGraphQL the extension does nothing.

It needs Barrio Suite.
